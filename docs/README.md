# Dokumentationsoverblik

Denne mappe samler projektets dokumentation.

## Læs i denne rækkefølge (anbefalet)

1. `optihus-fuld-forklaring-dansk.md`
   - Den mest grundige forklaring på dansk for ikke-tekniske og blandet publikum. Start med **kapitel 3** for tre-lags overblik, tekstdiagrammer og Mermaid-figurer, derefter mapper, hardware, TCP, konfiguration, Grafana og begrænsninger
2. `../README.md`
   - Hovedoverblik, build og drift
3. `quickstart-for-team-da.md`
   - Hurtig guide for teammedlemmer
4. `integration-test-checklist-da.md`
   - Checkliste for TCP/integrationstest
5. `architecture.md`
   - Teknisk arkitektur og dataflow
6. `optihus-dokumentation-udkast.md`
   - Rapport/driftsudkast på dansk
7. `md-struktur.md`
   - Forklaring af hvordan dokumenterne er organiseret
8. `tui-til-browser-ui-forhindringer-og-loesninger.md`
   - Kritisk gennemgang af konvertering fra TUI til Web ui samt løste fejl
9. `../deploy/boot-og-netvaerk-da.md`
   - Autostart på Raspberry Pi (systemd `.service`) og AP / Wi‑Fi-klient i OS
10. `../deploy/skabeloner-pi1-pi2-da.md`
   - Systemd-skabeloner; Pi 2 kopierer `miljoestyring_config.json.example` fra repo-rod til `miljoestyring_config.json`

## Mål med dokumentationen

- Let at forstå for ikke-specialister
- Præcis nok til vejleder/sensor
- Brugbar i både drift og rapport
